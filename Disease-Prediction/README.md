# Disease Prediction

Machine Learning project completed as part of my CodeAlpha internship.

## Objective

The objective of this project is to build a Machine Learning model that can predict the presence of heart disease based on various medical and health-related features.

## Dataset

This project uses the heart_disease.csv dataset.

The dataset contains medical information used to train and evaluate the machine learning model.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning

The project includes the following steps:

1. Loading and understanding the dataset
2. Data preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature selection
5. Splitting the data into training and testing sets
6. Training Machine Learning models
7. Evaluating model performance
8. Predicting the presence of heart disease

## Model Evaluation

The models are evaluated using appropriate classification metrics such as:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Project Files

- Disease prediction.ipynb - Jupyter Notebook containing the complete analysis and Machine Learning implementation.
- heart_disease.csv - Dataset used for training and testing the model.

## How to Run

1. Download or clone this repository.
2. Make sure Python and Jupyter Notebook are installed.
3. Open Disease prediction.ipynb.
4. Install the required Python libraries if necessary.
5. Run the notebook cells in order.
